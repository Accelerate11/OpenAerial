# 大型资源索引

[中文](README.md) | [English](README.en.md)

当前尚无数据集、模型权重或大型日志资源。

资源条目按真实需要建立，并记录：

- 稳定标识、名称、类型与所属产品。
- 来源、作者或维护方、适用许可。
- 固定版本或准确修订。
- 可用下载位置、文件格式和大小。
- SHA-256，以及获取后的核对方式。
- 采集、训练或生成条件，以及对应软件与配置。

需要受控版本管理的大型设计源文件可按实际需要使用 Git LFS。数据集、权重与大型原始日志使用适合的外部存储，在本目录保留版本和校验信息。

产品自身的训练与验证说明引用对应资源条目；产品发布清单固定实际采用的资源。小型必要示例可放在相关模块并注明用途。
