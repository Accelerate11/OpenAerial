# Large resource index

[中文](README.md) | [English](README.en.md)

No datasets, model weights, or large log resources have been registered yet.

Add entries when needed and record:

- Stable identifier, name, type, and associated product.
- Origin, author or maintainer, and applicable license.
- Fixed version or exact revision.
- Download locations, format, and file size.
- SHA-256 and retrieval verification procedure.
- Collection, training, or generation conditions and corresponding software and configuration.

Large design sources needing version control may use Git LFS as appropriate. Store datasets, weights, and large raw logs on suitable external storage, retaining version and checksum records here.

Product training and validation instructions reference the relevant entries, while release manifests fix resources actually used. Necessary small examples may live with the relevant module, with their purpose documented.
