# 机械结构

[中文](README.md) | [English](README.en.md)

当前尚无机械设计文件。

- [source](source/README.md)：零件、装配体及必要引用的可编辑源文件。
- [exports](exports/README.md)：与设计修订一致的交换、打印或加工文件。
- [drawings](drawings/README.md)：包含制造和检验要求的工程图。

选定工具后记录名称、版本、库依赖、坐标与单位约定，以及打开和导出步骤。

零件编号与[整机 BOM](../bom/bom.csv)对应。设计变化时同步核对导出文件、工程图和[装配说明](../docs/assembly.md)。
