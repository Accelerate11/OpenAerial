# Product configurations

[中文](README.md) | [English](README.en.md)

Store actual hardware combinations, firmware parameters, runtime configuration, and calibration examples here. No configuration or runnable parameter files have been defined.

Create a stable `<configuration-id>/` for each actual configuration and record:

- Applicable mechanical, board, and BOM revisions.
- Firmware, software, and sensor versions.
- Parameter meanings, units, coordinate frames, and calibration methods.
- Matching validation records.

Mark calibration values used only as formatting examples accordingly. Record calibration results for the actual device.
