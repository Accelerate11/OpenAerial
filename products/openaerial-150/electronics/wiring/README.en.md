# Power and wiring

[中文](README.md) | [English](README.en.md)

This directory records module connections, power distribution, harnesses, and interfaces for OpenAerial 150. No wiring design has been verified yet.

[connections.csv](connections.csv) is a header-only template. Record both endpoint modules, ports, pins, signal, nominal voltage, protocol, and cable specification for each actual connection. Explain non-applicable blank fields in the notes.

Module identifiers should match the [system BOM](../../bom/bom.csv) and release manifest. Store wiring diagrams, harness drawings, and photographs here with applicable revisions and configurations.

See [MicoAir743](../flight-controller/README.en.md), [ESC](../esc/README.en.md), and the [assembly guide](../../docs/assembly.en.md).
