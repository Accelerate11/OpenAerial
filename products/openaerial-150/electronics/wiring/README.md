# 供电与接线

[中文](README.md) | [English](README.en.md)

本目录维护 OpenAerial 150 的模块连接、供电分配、线束和接口记录。当前尚无经过核对的接线方案。

[connections.csv](connections.csv) 为连接记录模板，目前仅含表头。每条实际连接记录两端模块、端口、引脚、信号、标称电压、协议与线材规格；不适用字段留空并在备注中说明。

连接记录中的模块标识应与[整机 BOM](../../bom/bom.csv)及发布清单对应。实际接线图、线束图与照片可存放在本目录，并标注适用硬件修订和配置。

飞控资料见 [MicoAir743](../flight-controller/README.md)，电调资料见[电调](../esc/README.md)，装配顺序见[装配说明](../../docs/assembly.md)。
