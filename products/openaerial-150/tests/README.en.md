# Product validation

[中文](README.md) | [English](README.en.md)

Store bench checks, simulation validation, hardware test procedures, and necessary scripts here. There are no implemented tests or validation conclusions yet.

Record product revisions, configuration, firmware and software versions, conditions, procedures, acceptance criteria, actual results, and known issues. Define criteria before performing each experiment.

Put concise reports in [reports](reports/README.en.md). Index large raw logs in [Resources](../../../resources/README.en.md), fixing their origin, version, and checksum.

Distinguish validation scope by configuration and by simulation versus hardware. Release manifests reference completed validation only.
