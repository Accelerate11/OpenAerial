# 固件

[中文](README.md) | [English](README.en.md)

飞控已选择市售 MicoAir743。实际采用的飞控固件、版本和电调固件尚待补充，当前没有固件源码与可烧录文件。

硬件资料见 [MicoAir743](../electronics/flight-controller/README.md)。官方支持的固件范围仅作为选型参考，项目发布时另行记录实际使用并验证的固件目标与版本。

后续记录自研源码入口、目标硬件、编译工具和烧录方式。使用上游项目时记录来源、准确版本或提交、本地补丁与适用许可。

产品配置与参数放入 [configs](../configs/README.md)，在[部署说明](../docs/deployment.md)中说明固件与配置的配套关系。发布的固件二进制应记录来源版本与 SHA-256。
