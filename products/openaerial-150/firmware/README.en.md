# Firmware

[中文](README.md) | [English](README.en.md)

The selected flight controller is the commercial MicoAir743. Its installed firmware and version, plus ESC firmware, remain pending. No firmware sources or flashable binaries are included yet.

See [MicoAir743](../electronics/flight-controller/README.en.md) for hardware references. Manufacturer firmware support is a selection reference; product releases record the actual target and version used and validated.

Document original source entry points, target hardware, build tools, and flashing. For upstream projects, record origin, exact version or commit, local patches, and licensing.

Put product parameters in [configs](../configs/README.en.md), and document firmware/configuration compatibility in [deployment](../docs/deployment.en.md). Published binaries should include source version and SHA-256.
