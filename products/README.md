# 产品工作目录

[中文](README.md) | [English](README.en.md)

每款产品使用稳定目录名，内部同时组织设计、制造、软件与验证资料。

第一款产品为 [OpenAerial 150](openaerial-150/README.md)，目录标识为 `openaerial-150`。

## 新增产品

1. 在本目录下建立 `<product-id>/`，命名使用小写英文、数字和短横线。
2. 按 OpenAerial 150 的组织方式建立适用目录和说明；新产品的设计、参数与验证结论独立填写。
3. 在产品 README 中记录名称、用途、状态、规格与复现入口。
4. 创建产品自己的整机 BOM、变更记录与发布清单。
5. 更新根目录的产品目录表。

没有实际内容的技术模块保持待定义；未采用的模块在产品 README 中说明不适用。

## 成熟度

- 规划中：需求、规格和方案尚在定义。
- 设计中：正在补充设计或实现资料。
- 样机验证：已具备样机，正在记录验证结果。
- 可复现发布：已明确配套版本，具备公开的复现资料和验证范围。

同一产品的可选配置放在其 `configs/` 中。真正被多个产品复用的自研模块再提取至 `shared/`。
