# 许可与来源记录

[中文](licensing.md) | [English](licensing.en.md)

OpenAerial 的目标是开放产品从机械结构到软件与验证的完整资料。当前尚未确定自研资产的许可证，目录建立不代表许可已经授予。

## 待明确的范围

| 资产 | 当前范围 | 许可证状态 |
| --- | --- | --- |
| 品牌素材 | `assets/branding/` | 待确定 |
| 机械结构与工程图 | 各产品 `mechanical/` | 待确定，尚无设计文件 |
| 自研原理图、PCB 与制造资料 | 后续产品实际开展的板卡设计 | 待确定，当前尚无自研板卡 |
| 市售飞控与电调资料 | OpenAerial 150 的模块选型和集成资料 | 原厂资料按厂商实际发布与适用许可引用；本项目集成文档许可待确定 |
| 固件、软件及训练代码 | 产品目录与未来公共模块 | 待确定，尚无代码 |
| 文档 | 平台与产品文档 | 待确定 |
| 模型、数据与日志 | 未来资源索引所列资产 | 随具体资源逐项记录 |

## 记录方式

确定许可证后，加入对应许可文本，并明确它覆盖的目录或文件。必要时通过文件头或模块说明标注具体归属。

第三方源文件、库、模型和数据保留其原有许可证与署名。逐项记录来源、固定版本、适用许可、本地修改和获取方式。

市售模块的原厂设计资料是否公开，以厂商实际发布为准。项目分别记录自研结构、集成文档与第三方资料的来源和适用范围。
