# Licensing and provenance

[中文](licensing.md) | [English](licensing.en.md)

OpenAerial aims to share complete product development materials, from mechanical design to software and validation. Licenses for original assets have not yet been selected. Establishing directories does not itself grant a license.

## Scope to be defined

| Asset | Current scope | License status |
| --- | --- | --- |
| Brand assets | `assets/branding/` | Pending |
| Mechanical designs and drawings | Product `mechanical/` directories | Pending; no design files yet |
| Original schematics, PCB and manufacturing files | Future original board designs | Pending; no original boards yet |
| Commercial flight controller and ESC materials | OpenAerial 150 selection and integration records | Reference manufacturer materials under their published scope and applicable terms; project integration documentation license pending |
| Firmware, software and training code | Product directories and future shared modules | Pending; no code yet |
| Documentation | Platform and product documents | Pending |
| Models, data and logs | Assets listed in future resource indexes | Record per resource |

## Recording licenses

Once selected, include license texts and specify the directories or files they cover. Use file headers or module documentation where needed to clarify ownership.

Third-party sources, libraries, models, and data retain their original licenses and attribution. Record origin, fixed version, applicable license, local modifications, and retrieval method.

The manufacturer determines which commercial module design materials are published. Track project-authored structures, integration documents, and third-party materials separately by provenance and scope.
