# 开发说明

[中文](development.md) | [English](development.en.md)

当前仓库仅包含目录、品牌素材与文档模板，没有统一的编译或运行入口。

## 工具链记录

每个实际引入的设计或软件模块都应在自身 README 中记录：

- 工具名称、准确版本与支持的操作系统。
- 必要的设计库、符号、封装或软件依赖。
- 打开、构建、导出或启动步骤。
- 可核对的输出结果及已知限制。

产品级的编译、安装与烧录说明放入产品的 `docs/deployment.md`。目前未预设 CAD 工具、飞控或中间件。

## 文件管理

文本文件使用 UTF-8。公共换行规则见根目录 `.gitattributes`。

说明文档以中文 `.md` 和同目录英文 `.en.md` 成对维护，提供语言切换链接。设计文件、代码和机器可读清单共用一份，原始资料保留原文。

设计源文件与必要的导出文件均应纳入版本管理。大型、频繁变更的二进制设计文件可按实际需要配置 Git LFS；配置前确认贡献者能够获取完整文件。

原始数据集、模型权重与大型运行日志通过[资源索引](../resources/README.md)记录。构建目录、缓存和本地环境文件不进入源码历史。

## 检查方式

随实际内容增加对应检查：机械文件可打开且引用完整，电路设计库齐备，BOM 与装配一致，软件可构建，参数与产品修订匹配。

自动化检查在有明确输入和验收目标后放入 `tools/`；产品专用验证放入产品 `tests/`。
