# Shared modules

[中文](README.md) | [English](README.en.md)

There are no modules shared across products yet.

When multiple products actually reuse original parts, boards, drivers, algorithms, or interfaces, create a module directory here. Record responsibilities, design or source entry points, interfaces, dependencies, versions, and applicable products.

Products keep their own BOMs, parameters, assembly instructions, and validation, and fix required shared module versions in their release manifests.
